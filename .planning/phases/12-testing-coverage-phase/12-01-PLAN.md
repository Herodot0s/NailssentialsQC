# Phase 12: Testing & Coverage

## Goal
Initialize the testing environment and implement comprehensive test coverage for backend and frontend, focusing on critical paths like Auth and Payroll.

## Context
Targets: 90% for Auth/Payroll, 80% for Backend, 70% for Frontend.

## Tasks
1. [ ] **Infrastructure Setup**
   - Fix backend Jest configuration (rename to .js, fix ESM/CommonJS conflicts).
   - Create frontend test wrapper for Vitest (Providers: QueryClient, Router, Auth).
   - Configure coverage reporting and scripts.
   - Add root-level `npm test` script to aggregate both backend and frontend suites.
2. [ ] **Backend Testing (Auth & Core)**
   - Implement unit and integration tests for Auth middleware and webhooks.
   - Achieve 90% coverage for Auth-related files.
3. [ ] **Backend Testing (Payroll Engine)**
   - Implement unit tests for `payrollEvaluator.ts`.
   - Implement integration tests for `payrollController.ts` covering all commission rates (5%, 8%, 10%, 20%).
   - Achieve 90% coverage for Payroll-related files.
4. [ ] **Backend Testing (General)**
   - Implement tests for Staff, Appointment, and Service controllers.
   - Achieve overall 80% backend coverage.
5. [ ] **Frontend Testing**
   - Implement component and hook tests for critical UI paths.
   - Achieve 70% frontend coverage.
6. [ ] **Regression Tests**
   - Add specific tests for timezone shifts in bookings.
   - Add tests for concurrency in appointment scheduling.
   - Add tests for checkout logic with addons.

## Success Criteria
1. Coverage targets met (90/90/80/70).
2. All regression scenarios (timezone, concurrency, checkout) are verified by tests.
3. CI/CD scripts for testing are functional.
