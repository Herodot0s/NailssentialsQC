# Plan - Install Frontend Testing Dependencies

Install Vitest and testing library dependencies in the frontend directory to enable component and unit testing.

## Steps
1. Navigate to the `frontend/` directory.
2. Install dev dependencies: `vitest`, `@vitejs/plugin-react`, `jsdom`, `@testing-library/react`, `@testing-library/jest-dom`, `@testing-library/user-event`, and `msw`.
3. Verify `package.json` updates.
4. Update `STATE.md` to reflect the new testing infrastructure.
