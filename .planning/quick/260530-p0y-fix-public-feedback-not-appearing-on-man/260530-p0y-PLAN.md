# Quick Plan: Fix Public Feedback Not Appearing on Manager Dashboard

## Root Cause Analysis

The feedback data exists in the Neon DB but doesn't render on the Manager Dashboard → Client Care → Public Feedback tab due to two bugs:

1. **Primary: `tags: null` crash** — `ReviewModeration.tsx:82` does `(review.tags as string[]).map(...)`. The Prisma schema defines `tags` as `Json?` (nullable). Any review with `tags: null` crashes the entire component with `Cannot read properties of null (reading 'map')`, causing a blank render.

2. **Secondary: `Promise.all` cascade failure** — `ManagerDashboard.tsx:189` wraps 6 API calls in `Promise.all`. If any single call fails (401, 500, network), the catch block fires and `setReviews()` is never called. Reviews stay as empty `[]`.
